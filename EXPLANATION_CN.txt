作业目的与实现说明

一、这份作业要解决什么问题？
作业要求用 TCP 构建一个多人聊天服务。多个客户端同时连接服务器，用户从控制台输入文字；服务器负责接收、转发消息，并通知其他人有用户加入、退出或断线。重点是理解网络通信和并发，而不是图形界面。

二、实现采用什么结构？
ChatServer 使用 ServerSocket 监听端口。每接受一个 Socket，就为该客户端创建一个线程，因此一个客户端等待输入时不会阻塞其他客户端。每个处理线程读取一行文本，并通过 PrintWriter 将消息发给目标连接。ChatClient 也使用一个后台接收线程，使用户可以一边看消息、一边输入。

三、怎样处理并发？
服务器维护在线用户名到连接处理器的映射。多个客户端线程可能同时加入、发送或退出，因此共享的频道路由操作使用同步锁保护；在线表和封禁表使用并发集合。每个客户端输出也通过同步方法写入，避免多个线程同时写同一连接造成行交错。

四、完成的功能
1. 基础聊天：普通用户消息转发给其他合适的在线用户，并携带发送者名称。
2. 生命周期提示：加入、正常退出、断线都会广播通知。
3. 用户权限：服务器启动时设置管理员密码；使用正确密码登录的用户是超级用户，其余用户是普通用户。
4. 永久封禁：超级用户可用 /ban 用户名 封禁账号。封禁名单写入 banned-users.txt，服务器重启后仍然有效。
5. 私聊扩展：用 /private 用户名 建立一对一私聊，用 /public 返回公聊。私聊双方仍能收到其他未处于私聊中的用户所发公聊消息。其他人收不到这对用户之间的消息，也收不到这对用户发出的公聊消息。断线时私聊关系自动解除。

五、命令与运行
在本目录执行：
  javac ChatServer.java ChatClient.java
  java ChatServer 5000 myAdminSecret
另开终端运行客户端：
  java ChatClient localhost 5000
登录普通用户时输入：alice
登录超级用户时输入：admin myAdminSecret
客户端命令：/private bob、/public、/ban bob（仅超级用户）、/quit。服务器端可用环境变量 CHAT_ADMIN_PASSWORD 提供管理员密码；若命令行未传密码且环境变量也未设置，则不会授予超级用户权限。

六、题目涉及的课程内容
实现直接运用了 TCP 客户端/服务器通信（ServerSocket、Socket）、线程（Thread）、并发共享状态与同步（ConcurrentHashMap、并发集合、synchronized）、文本流 I/O 和连接关闭处理。消息以换行符作为简单协议边界，因此每条聊天消息占一行。
